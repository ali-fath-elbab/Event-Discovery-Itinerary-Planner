# Event Discovery Itinerary Planner

## Team Members
- Ali Fath Elbab

## Project Description
Event Discovery Itinerary Planner helps users discover events and organize selected events into a practical itinerary.

## Repository Structure
- `/docs` - Submitted documents (proposal, UI/UX design, reports, testing evidence)
- `/frontend` - Frontend source code (React + Tailwind + HTML5)
- `/backend` - Mock data and API integration code
- `/tests` - Test cases and manual test reports
- `/deployment` - Deployment and environment setup instructions/configuration

## Setup and Run Instructions

### Frontend
1. Navigate to the frontend folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the frontend development server:
   ```bash
   npm run dev
   ```

### Backend (Mock Data/API Integration)
1. Navigate to the backend folder:
   ```bash
   cd backend
   ```
2. Add mock data files and backend/API integration code as needed.
3. Run backend services with the scripts/configuration that will be added in this folder.
