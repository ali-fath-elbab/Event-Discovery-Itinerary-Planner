# Manual Test: Repository Structure and README Compliance

## Scope
Validate that required top-level folders exist and root README includes required sections.

## Test Cases
1. Verify folders exist: `docs`, `frontend`, `backend`, `tests`, `deployment`.
2. Verify root `README.md` includes:
   - Project title and team members
   - Short project description
   - Setup/run instructions for frontend and backend mock data
   - Links to relevant `/docs` files

## Expected Result
All checks pass.
